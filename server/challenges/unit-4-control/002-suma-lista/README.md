# Suma con For

## Descripción

Tienes una lista de números `[1, 2, 3, 4, 5]`. Usa un ciclo `for` para sumar todos los elementos e imprime el resultado.

## Ejemplo

### Output esperado

```
15
```

## Instrucciones

1. Crea una lista `numeros` con los valores `[1, 2, 3, 4, 5]`.
2. Crea una variable `suma` inicializada en 0.
3. Usa un ciclo `for` para recorrer la lista y sumar cada elemento a `suma`.
4. Imprime el valor final de `suma`.
