# Par o Impar

## Descripcion

Dado un numero `n = 7`, imprime "par" si el numero es par, o "impar" si es impar.

## Ejemplo

### Output esperado

```
impar
```

## Instrucciones

1. Crea una variable `n` con el valor 7.
2. Usa un condicional `if/else` para verificar si `n` es par o impar.
3. Un numero es par si el residuo de dividirlo entre 2 es 0 (`n % 2 == 0`).
