# Concatenar Strings

## Descripción

Tienes dos variables `palabra1` y `palabra2` con los valores "Hola" y "Mundo". Imprime ambas palabras unidas con un espacio en medio.

## Ejemplo

### Output esperado

```
Hola Mundo
```

## Instrucciones

1. Crea una variable `palabra1` con el valor "Hola".
2. Crea una variable `palabra2` con el valor "Mundo".
3. Imprime ambas palabras unidas con un espacio: `"Hola Mundo"`.
