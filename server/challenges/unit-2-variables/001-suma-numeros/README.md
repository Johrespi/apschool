# Suma de Numeros

## Descripcion

Crea dos variables `a` y `b` con los valores 5 y 3 respectivamente. Luego imprime la suma de ambas.

## Ejemplo

### Output esperado

```
8
```

## Instrucciones

1. Crea una variable `a` con el valor 5.
2. Crea una variable `b` con el valor 3.
3. Imprime la suma de `a + b`.
